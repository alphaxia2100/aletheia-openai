# Consilient Atlas

The accreting knowledge base. Each completed survey is appended here as a dated markdown note so surveys **compound** instead of restarting from blank (the "agentic Obsidian" / LLM-wiki pattern).

Layout:
- `index.md` — running table of contents of all surveys and the spiky POVs they produced.
- `surveys/<yyyy-mm-dd>-<slug>.md` — one file per survey (written by the `consilient-atlas` skill).
- `claims/` — optional: extracted claims with their provenance verdicts, for cross-survey reuse.

Nothing here is generated at scaffold time; the `consilient-atlas` skill writes into it. It is tracked in git on purpose — this store is the point.
